# Integrated Home studies for issue #29

Run `node prototypes/issue-29/serve.mjs` from the repository root, then open
`http://localhost:8765/`. Set `PORT` to use another port.

The six current studies live in `v2/`. Each composes the welcome text, command
bar, and Reading/Stats desk as one visual space:

1. **Shared frame:** all three elements live inside one continuous frame.
2. **Split desk:** greeting and direct field share a column beside the paper.
3. **Task rail:** the task chooser forms the left edge of the reading workspace.
4. **Editorial sheet:** greeting, direct field, and paper share one reading axis.
5. **Scroll handoff:** the field compresses into a sticky dock as the paper enters.
6. **Reading first:** the paper leads; greeting and task bar form its edges.

Keyboard proposals: `/` or `Ctrl/Cmd+K` focuses the field; `S`, `O`, `A`,
and `U` select Search, Open, Add, and Upload; `T` toggles Reading/Stats;
`J`/`K` select papers; Enter opens the selected paper; `?` opens help.
Shortcuts do not capture keystrokes while typing. The previous four studies
remain at the root of this directory for comparison but are not linked from
the index.

This is a design review artifact. Paper data is illustrative, and actions show
prototype feedback rather than changing the library. Search ideas can inform
issue #3; the Open flow can inform issue #25.

The six static HTML pages are generated by `node prototypes/issue-29/v2/build.mjs`.
